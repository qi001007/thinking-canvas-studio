# studio_host

本地宿主包。`bridge_server.py` 提供 loopback WS JSON-RPC、token/Origin/allowlist；`host_service.py` 分发 app/workspace/boards/analysis/debug 方法，并调用 Python 或 Node 静态分析器；`workspace.py` 做路径约束、原子写与 boards；`language_packages.py` 加载四语言 manifest；`dap_session.py` 处理 DAP request_seq/事件/超时/反向请求；`scripted_adapter.py` 提供不执行进程的演示数据；`debug_service.py` 归一化事件并采集变量树；`execution_policy.py`、`host_approval.py`、`windows_supervisor.py` 负责原生确认后的单次 receipt、Job Object 限额与 debugpy 启动；`real_debug_service.py` 处理真实 DAP attach/变量采集；`workbench.py` 提供干净工作台与隐藏继承 context；`static_analysis.py` 用 Python AST 生成静态图；`graph_views.py` 做语言无关的总览/结构/数据过滤、聚焦与阅读上限。Linux 监管未实现。
