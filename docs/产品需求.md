# 产品需求

更新：2026-10-23。当前交付是可运行底座；Python 已接通函数工作台、AST 静态结构图、真实 debugpy + Windows Job Object，其余语言尚未接入。

## 用户要解决的问题

写算法函数时，尤其是把过程函数单独拆出来、对张量/容器/引用关系做变换时，需要同时在脑子里维护：代码、变量、容器结构、对象关系、调用栈和每一步变化。手动画布能表达思考，但逐张重画会拖慢写函数的速度。

目标是把这两件事合起来：**在代码编辑器旁自动呈现运行时的结构化状态；没有运行代码时，仍能自由手绘推演。**

## 技术现实（必须写进产品行为）

1. **编辑时无法知道运行时变量/内存**。只有启动并停在一个停点后，才有可展示的数据。输入时能做的是静态信息和已有 trace 回看。
2. **DAP 不是完整内存图**。它提供变量树、展示字符串和临时 `variablesReference`；对象身份、别名、堆块和原生内存需要额外采集器/适配器能力。没有证据时标“未知”，不猜。
3. **连续运行中的变化不是免费的**。DAP 主要在停点给数据；如果要逐步动画，需要自动单步、tracepoint 或适配器专用采集。底座只承诺已采集的暂停快照；缺失要显示 gap。
4. **手绘与调试事实分开**。调试快照只读；用户可以把快照复制成手绘板继续推演，但不能让运行时刷新覆盖手绘内容。

## 界面与渲染约束

- 页面默认简洁：主区域不放大段说明，每个区域最多一个副标题；详细解释进 tooltip/帮助；顶栏只保留文件、模式、主要运行控制和保存。
- 函数/栈帧/类用大方框表示，变量卡、函数框放在框内；框套框表示调用/包含关系，不再用平铺卡片加 `contains` 边硬凑。
- 函数框/类框/帧框不设尺寸上限，随子内容自然变大；画布通过平移/缩放/聚焦查看，不裁框内内容。
- 会无限增长的数据卡才有硬边界：数组/列表/矩阵/字典/结构/张量用窗口、分页、省略号和内部滚动，普通卡最大 560×360；单卡最多渲染 40 个单元格。
- 画布安全上限取高值：同时挂载卡片/子框 500、边 1,000、总 DOM 20,000；框内子项视口虚拟化，滚动/平移可到达全部；超限提示“视图过大”并切聚焦/折叠其他区域，必须显示摘要/`partial`。
- 增删要更新长度/页码并在越界时回退；赋值/读取/传参/返回边必须有证据和行号，包含关系用空间嵌套表达。
- 完整规则见 [canvas-card-spec.md](canvas-card-spec.md)。

## 底座验收

- 打开桌面窗口：从源文件新建函数工作台；写类/函数并保存；静态画布出现参数/字段/调用/循环关系；切换总览/结构/数据并用聚焦下钻类/方法；在 `__main__` 写测试输入；点真实运行并经过原生确认；debugpy 停在断点；切到运行视图看真实变量；单步后帧轴追加帧；停止后进程树回收。
- 语言：Python 工作台/静态图/真实调试；TS/JS 文件级静态图；C/C++/Java 静态图与真实调试未接时界面和文档明确标出。
- 工作台：干净编辑页；源文件 import/顶层定义继承；不修改源文件；源文件在确认后变化会使 receipt 失效。
- 完整运行：点“完整运行”后自动记录，不要求手动设置断点；结束后帧轴至少能看到函数体/测试入口的实际行；播放/暂停/调速可用；达到上限有明确提示。
- 手绘模式：添加数组/列表/字典/变量/便签；拖动；记录步骤；只读回看。
- 桥安全：错误 token 被拒绝；Origin 受限；消息大小有界；未知方法拒绝；真实运行需单次 receipt。
- 工作区：读写源代码；坏路径拒绝；画板 JSON 原子保存；坏文件不覆盖当前。
- 测试：类型检查、前端构建、Node 核心测试、Python 宿主测试全通过。
- 明确不把“脚本演示”标成真实调试；界面上有“脚本演示”标记；真实会话有“真实调试”标记。

## 不做

- 不复制整包 VSCode/Code-OSS workbench 或扩展市场。
- 不做云同步、账号、遥测。
- 不在没有受信 supervisor 时执行用户代码。
- 不承诺一次接入全部语言；不以 Python 成功代替其他语言验收。
- 不声称覆盖完整堆/GPU 内存或时间旅行调试。
