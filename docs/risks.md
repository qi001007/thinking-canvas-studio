# 风险与边界

更新：2026-10-23。

| 风险 | 影响 | 当前处理 / 门槛 |
|---|---|---|
| 脚本演示被误认为真实调试 | 用户相信了不存在的语言支持 | 浏览器明确“脚本演示”；桌面真实会话显示“真实调试”；其他语言未接 |
| 编辑时无法知道运行时内存 | 产品承诺失真 | 只承诺启动/停点后的采集；编辑时只显示静态信息/已有 trace |
| DAP 变量树不是完整内存图 | 画出不存在别名/内存 | 只用结构节点；别名需 collector 证据；未知/部分采集可见 |
| 连续运行没有逐步事件 | 动画承诺失真 | 只保存暂停快照；缺样标 gap；帧轴 500 上限；完整运行用自动 continue 记录真实暂停帧 |
| 运行中修改断点 | 用户以为新断点生效 | 当前只在启动时下发；后续加 `setBreakpoints` 同步 |
| 静态 AST 被误当运行时事实 | 用户相信不存在的对象/别名 | 静态图标记 origin/虚线；未知不伪造；结构/运行双视图 |
| 工作台继承执行源文件顶层代码 | 触发源文件副作用 | 原生确认显示继承上下文；`__main__` 不执行；后续加导入模式选择 |
| 大型类/递归/张量静态图 | 画布拥挤、不可读 | 预算 320 节点；最小缩放 68% + 平移；后续聚焦/折叠 |
| 500 帧上限丢旧帧 | 用户误以为历史完整 | 显示“保留最近/丢弃”计数；trace 持久化后续 |
| 自动逐行记录改变时序 | 用户以为原程序就是这么慢 | 明确是调试器自动停/继续；不改变逻辑但改变速度；后续可加 trace hook |
| 只记录当前文件 | 跨文件调用缺少逐行帧 | 当前文件所有可执行行；跨文件栈可见但被调函数不逐行；后续补
| debugpy 版本/解释器不匹配 | 启动失败/断点漂移 | 宿主解释器运行 debugpy；manifest 记录版本；失败显式报错 |
| DAP 临时句柄复用/晚回包 | 旧状态覆盖新帧 | run/session/stopEpoch 校验；`DebugModel` 拒绝旧帧；测试覆盖 |
| 真实运行授权被绕过 | 用户代码/进程失控 | 原生确认；单次 120 秒 receipt；config digest 含源文件 SHA-256；无 supervisor 不放行 |
| Windows Job Object 不是沙箱 | 文件/网络访问仍开放 | UI/文档明确；后续需要权限模型，不宣称虚拟机隔离 |
| WS 桥被本机网页滥用 | 文件读写/调试控制 | loopback、token、Origin、allowlist、2 MiB 上限；仍不是恶意代码沙箱 |
| pywebview 窗口/IME/DPI | 白屏、输入错、快捷键冲突 | 代码已写；必须真窗口验收，不能只浏览器 |
| Monaco 包体 | 启动/内存压力 | 主包约 3.0 MB gzip 0.8 MB；LSP 接入前测体积 |
| `ScriptedDapAdapter` 能力有限 | 真实容器语义不足 | 只用于演示；真实 debugpy 接入时替换采集 |
| 手绘能力缩水 | 用户失去旧版体验 | 当前仅基础卡片/步骤；笔迹/连线/文本编辑待补 |
| 工作区坏文件/原子写失败 | 数据丢失 | 临时文件 + fsync + replace；坏 JSON 拒绝；需要增加恢复测试 |
| EPL/GPL 依赖 | 分发合规 | GDB/Java 外置、不并入 MIT；发布前 SBOM/许可专项 |
| 四语言同时推进 | 长期停在 spike | Python 垂直闭环优先；其他语言逐个验收 |
| 真窗口 API 注入慢 | “窗口出现”但桥不可用 | 前端等待 `bridge_info`；不能以窗口出现当桥就绪 |
