## 运行入口

- 浏览器：`npm run dev` → `http://127.0.0.1:5173/`（DemoHost，不执行代码）。
- 桌面：`npm run build` → `python desktop/app.py`（pywebview + Python WS 桥）。
- 开发桌面：`python desktop/app.py --dev`（窗口加载 Vite）。
- 宿主自检：`python desktop/app.py --smoke`。

## 关键不变量

- 运行身份 `sessionId/runId/stopEpoch` 必须校验；旧回包丢弃。
- `RuntimeHandle` 不持久化；`TraceSnapshot` 剥离句柄。
- 手绘与调试事实分开；共享 Scene/Card 渲染器，不共享写入路径。
- 没有 supervisor 不执行用户代码；脚本演示必须标记。
- 不根据展示字符串猜地址/别名；未知/部分采集可见。
