## 已知限制（写在产品里，不藏）

- 编辑时没有运行时变量/内存；不要用静态推测冒充实测。
- DAP 变量树不是完整内存图；临时句柄不能持久化。
- 脚本化 DAP 是演示数据，不能作为真实语言支持证据。
- 真实 Python 运行必须经过原生确认；没有 supervisor 或文件在确认后变化，不放行。
- Windows Job Object 只限制进程资源，不是文件/网络沙箱。
- 浏览器通过不等于 pywebview 窗口通过；两者分别验收。
