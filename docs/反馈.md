### 调试能力（P0，先做）

- [x] 长数组/长容器：默认显示首尾窗口、总数和省略号；可展开/分页继续看，不静默截断。
  - 判据实测：真实 debugpy fixture `nums = list(range(100000))` 首批 100 项，分页读取第 100 项起的 5 项成功；UI 冒烟中显示“加载更多 · 已显示 100”，点击后 101→151；画布卡片只渲染 20 项窗口 + `…`/已显示数量，不再平铺全部。
- [x] Watch/监视：可添加表达式，每个停点刷新；坏表达式显示错误。
  - 判据实测：真实停点添加 `len(nums)`，Watch 显示 `1000`；停点代际校验保留。
- [x] 求值/REPL：调试控制台可在当前栈帧输入表达式；求值执行用户代码，必须在初始原生确认中明确授权。
  - 判据实测：REPL 输入 `len(nums)` 返回 `1000`；原生确认文案包含“允许在当前停点执行 Watch/REPL 表达式”；未授权能力为 false。
- [ ] 断点类型：条件、命中次数、日志断点、异常断点；运行中可更新。
  - 判据：`i == 5` 只在成立时停；日志断点输出后继续；运行中新增断点在下一次停点生效。
- [ ] 改变量、暂停、重启、线程/栈分页、调试控制台。
  - 判据：改 `x=42` 后下一停点读到 42；长循环可暂停；重启清空旧帧并重新授权；多线程栈可分页切换。
- [ ] 能力矩阵：VSCode 有的功能逐项列出；适配器不支持时置灰并说明，不伪造。

### 运行时画布（P1，调试数据模型之后）

- [ ] 函数/栈帧是容器：变量卡放在函数容器内部，活动帧高亮，调用帧可折叠。
  - 判据：截图中不存在漂浮的局部变量；切换栈帧时容器和内部变量一起切换。
- [ ] 赋值/读取/传参/返回边：从语句/变量指向目标，边带 `line` 和关系标签；只在有 AST 证据和值变化时画。
  - 判据：`total += value` 执行后出现指向 `total` 的写入边；值未变时不画。
- [ ] 循环轨道：按迭代序号展示当前轮、循环变量和关键数据；回放与帧对齐。
  - 判据：冒泡排序 fixture 显示 4 轮迭代、当前轮、`i/j/swapped` 每轮值；滑块和轨道同步。
- [ ] 张量卡：shape/dtype/device/切片预览；无元数据时显式未知；求值读取元数据要授权。
  - 判据：numpy/PyTorch fixture 显示 shape 和 dtype；没有元数据时不伪造。
- [ ] 基础控件规范化 + 图例：类/函数/变量/参数/循环/调用各有固定形状、颜色、徽标；静态/运行时/手绘可区分；三个静态视图有不同说明和图例。
  - 判据：不读标题也能区分三视图与静态/运行时；图例可开关。
- [ ] 步进/回放传递动画：变化卡高亮、上一值残影、写入边加粗；回放明确不重新执行。
  - 判据：单步后能看到写入边和旧值；回放滑块切换时边/高亮同步。

### 卡片边界、容器画法与页面减法（补充批注）

规范：[canvas-card-spec.md](canvas-card-spec.md)。

- [ ] 函数/栈帧就画成一个大方框：标题在框上沿，变量卡放在框内；框套框表示调用关系，不再把局部变量散在框外。
  - 判据：截图里每个局部变量都在某个函数框内；框与框的包含关系一眼可见。
- [ ] 上限只加给会无限增长的数据卡：普通数组/张量/字典/结构卡最大 560×360；函数框、类框、帧框**不设上限**，随子卡/子框自然变大，类套函数时类框比函数框大。
  - 判据：10,000 项数组保持固定卡片窗口；1,000 个局部变量让函数框变大而不是被截断；类框完整包住内部函数框，画布可平移/缩放/聚焦。
- [ ] 内容窗口：数组/列表 20 项/页，矩阵 6×8，字典/结构 12 项/页；首尾省略号 + 翻页/内部滚动；同时渲染不超过 40 个单元格。
  - 判据：100,000 项数组首屏只渲染一个窗口，显示总数、范围和省略号；翻页/滚动只换窗口，不创建 10 万个 DOM 节点。
- [ ] 增删与关系：新增/删除更新长度和页码；越界页回退；赋值/读取/传参/返回边带行号，包含关系不再逐项画 `contains` 边。
  - 判据：删掉当前页最后一项时页码回退；`total += value` 后出现带行号写入边；函数框内变量不画 `contains` 线。
- [ ] 画布安全上限取高值：同时挂载 500 张卡/子框、1,000 条边、20,000 个 DOM 元素；框内子卡视口虚拟化，滚动/平移可到达全部；超限提示“视图过大”并切聚焦/折叠其他区域，不裁当前框内内容。
  - 判据：1,000 个变量的函数框能滚动看到全部，但同一时刻挂载不超过 500 张；500+ 卡/边 fixture 仍可交互；不白屏、不冻结、不静默截断。
- [ ] 页面文字减法：主区域不放大段说明；每个区域最多一个副标题；顶栏只留产品名、文件、模式、主要运行控制和保存；说明进 tooltip。
  - 判据：1680×1050 首屏没有超过一行的说明段落；文件和运行入口能在 1 秒内被识别。

## 已知限制（写在产品里，不藏）

- 编辑时没有运行时变量/内存；不要用静态推测冒充实测。
- DAP 变量树不是完整内存图；临时句柄不能持久化。
- 脚本化 DAP 是演示数据，不能作为真实语言支持证据。
- 真实 Python 运行必须经过原生确认；没有 supervisor 或文件在确认后变化，不放行。
- Windows Job Object 只限制进程资源，不是文件/网络沙箱。
- 浏览器通过不等于 pywebview 窗口通过；两者分别验收。
