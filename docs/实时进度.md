## 实测记录

- `npm run typecheck`：通过。
- `npm test`：19 项通过（生命周期、投影、卡片、差异、手绘步骤、预算）。
- `python -m unittest discover -s desktop/studio_host/tests -t desktop -v`：50 项通过（策略、DAP 帧、桥、工作区、语言包、脚本 DAP、真实 debugpy、Job Object）。
- `npm run build`：通过；Monaco 主包约 3.0 MB，gzip 约 0.8 MB。
- 浏览器真机（1680×1050，无头 Edge + CDP）：Monaco 渲染；脚本会话停点出现 4 张卡片；步过后 2 张卡片/1 个单元格高亮；时间线追加停点；手绘模式加数组、记录步骤成功。
- Python WS 桥真机链路：浏览器 → WS `debug.start` → 脚本 DAP → `framesLoaded` → 画布/变量/时间线；步过 `stopEpoch` 1→3，数值变化正确。
- `python desktop/app.py --smoke`：桥启动、工作区列表 3 个文件、端口有效。
- pywebview 隐藏窗口 + WebView2：加载 `frontend/dist`，`bridge_info` 注入，界面显示“本地桌面宿主”。
- 真实运行链路：隐藏窗口点击“真实运行” → 原生确认框点击“确定” → debugpy 停到 `main.py:7` → 4 张卡片、变量 `nums/seen/i/j/n/swapped`、时间线 1 个停点；步过后 `main.py:8`、`seen={5:0}`、时间线 2 个停点；停止后 Job Object 回收。
- 真实 debugpy 集成测试：`fixture.py` breakpoint、locals、list 子项、单步 `total 0→1`、stop；Job Object wall timeout 测试通过。

## 不算成功的地方

- 脚本化 DAP 不等于真实调试；浏览器截图不替代 pywebview 窗口验收。
- 手绘编辑器目前只是基础卡片/步骤，不是旧版完整笔迹/连线体验。
- 连续运行中的每次赋值没有采集；只保存已发生的暂停快照。
- 没有 supervisor，所以“运行演示”只能跑内存脚本，不能运行用户代码。
